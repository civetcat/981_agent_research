# Project Roadmap & Task Tracker (GrannyTrade)

## 📌 專案概覽
- **目標**：開發一套跨平台、易部署的自動化交易 Toolbox，支援比特幣小額策略實驗，強調「極簡化」與「Agent 協作」。
- **當前階段**：規劃與環境建置中
- **最後更新**：2026-05-15

---

## 🛠 功能規劃與設計思維 (Strategy)

1. **核心連接模組 (Granny-Core)**：
   - **目的**：標準化各交易所 API。
   - **設計理由**：使用 CCXT 確保未來更換標的（如 ETH）時無需修改核心代碼。[cite: 3, 4]

2. **Telegram 遠端控制台 (Granny-Console)**：
   - **目的**：達成跨手機、平板的無縫操作。
   - **設計理由**：通訊軟體介面最直覺，即使對電腦不熟的使用者也能透過對話框下指令。[cite: 3]

3. **一鍵部署環境 (Granny-Deploy)**：
   - **目的**：實現「抓下來就能跑」的用戶體驗。
   - **設計理由**：利用 Docker 封裝所有依賴項，消除不同系統間的環境差異。[cite: 4]
