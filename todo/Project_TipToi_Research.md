Project Tip-Toi-Reveng: 點讀筆應用與逆向工程研究
📝 專案描述
深入研究開源專案 tip-toi-reveng，探索點讀筆與數位紙張（OID 編碼）的互動原理。目標是擺脫封閉系統限制，實現自製點讀教材的高自由度開發。

🔍 技術細節與研究紀錄
本專案核心聚焦於以下技術領域，根據過去紀錄整理如下：

1. OID (Optical Identification) 編碼原理
底層技術：研究松翰科技 (Sonix) 的 OID 編碼。點讀筆透過前端 CMOS 感測器配合紅外光，讀取印刷品上微小的點陣碼（隱形碼）。

印刷要求：

600dpi+ 雷射列印：確保點陣碼的解析度足以被感測器識別。

K100 純黑碳粉：利用碳粉吸收紅外光的特性，避免彩色碳粉干擾（彩色碳粉對紅外光通常是透明的）。

微距驗證：利用 Sony A73 或手機微距鏡頭驗證列印出的點陣碼完整性。

2. tttool 工具鏈應用
YAML 腳本開發：使用 tttool 撰寫 YAML 腳本，定義 media-id 與對應的音訊觸發邏輯。

檔案封裝：研究將音檔與邏輯封裝成 .gme 檔案格式的過程。

開源社群參考：參考 GitHub 上關於硬體版本（如 G1, G2, G3 代）的固件差異與加密機制討論。
