# Project Roadmap & Task Tracker

## 📌 專案概覽
- **目標**：建置 RTX 3060 多模型地端環境，並開發 Hermes Agent 的自由切換與自動化場景路由系統。
- **當前階段**：規劃中
- **最後更新**：2026-05-15

---

## 🛠 功能規劃與設計思維 (Strategy)

1. **本地多模型矩陣部署 (Multi-LLM Matrix)**：
   - **目的**：解決單一模型無法兼顧「推理速度」與「邏輯深度」的問題。
   - **設計理由**：利用 RTX 3060 12GB 顯存，同時或交替載入不同優勢的 GGUF/量化模型（如 Qwen 負責速度，DeepSeek-R1 負責思考）。

2. **動態大腦切換器 (Dynamic Brain Switcher)**：
   - **目的**：讓 Hermes Agent 可以不重啟、無縫切換地端與雲端 AI。
   - **設計理由**：封裝 Ollama API 與 雲端 API，提供統一的 `switch_model(model_name)` 接口給 Agent 調用。

3. **專案情境守護者 (Context Guardrail & Router)**：
   - **目的**：防止 Agent 在錯誤的場景使用錯誤的模型（如用小模型讀大檔案導致遺忘，或雲端洩漏隱私）。
   - **設計理由**：建立自動化檢驗機制，偵測 Token 長度與任務關鍵字，錯配時自動發出提示。
