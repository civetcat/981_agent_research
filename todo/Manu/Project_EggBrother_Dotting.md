# Project EggBrother: 《雞蛋哥哥》繪本點讀化

## 📝 專案描述
將繪本實體書數位化並點讀化，透過 AI 工具優化從「音軌切割」到「教材製作」的自動化工作流。

## 🛠 核心技術與自動化

### 🎙️ AI 音訊自動切割監控工具 (`audio_sync_agent.py`)
本工具專為點讀教材、有聲書等需要「大量精細切割」的音訊專案設計。透過監控 JSON 設定檔的變化，實現「存檔即切割」的高效工作流，並解決網路共享磁碟 (Samba/NAS) 的快取延遲問題。

#### 🌟 核心特色
- **差異化更新**：僅重新切割 JSON 中被修改過的段落，實現毫秒級回饋。
- **Snap-to-Silence**：AI 自動吸附靜音區進行精準切割（預設搜尋範圍 800-1500ms）。
- **Hot-Reload & 防快取**：自動跳轉檔名版本（例如 `_v1`, `_v2`），確保聽到的永遠是最新版本，徹底解決快取延遲。
- **精確毫秒支援**：時間戳記支援 `MM:SS.mmm` 格式（例：`01:25.500`）。
- **預載優化**：原始音檔僅載入一次至記憶體，大幅提升處理速度。

#### 🚀 快速啟動
請確保環境已安裝 Python 3.8+ 與 **FFmpeg**。

```bash
# 安裝必要套件
pip install pydub watchdog

# 執行監控
python audio_sync_agent.py --src "來源音檔.mp3" --json "01.json" --margin 1500

### 📖 工作流建議

*   **標記階段**：初次填寫秒數並開啟 `"auto_adjust": true` 進行 AI 靜音自動吸附。
*   **微調階段**：手動修正毫秒數值，存檔後觸發 Hot-Reload 即時聽取成果。
*   **鎖定階段**：滿意後將 `"auto_adjust": false`，防止後續邏輯影響已設定的精確時間點。
