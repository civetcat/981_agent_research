# TipToi 專案：1200 DPI 雷射印表機選購與維修指南

## 📝 選購核心需求
針對 TipToi OID 碼的列印，硬體必須滿足以下條件以確保點讀筆感應成功：
- **物理解析度**：必須達到真實 **1200 x 1200 dpi**（非軟體模擬），確保點陣碼邊緣銳利[cite: 1, 2]。
- **碳粉特性**：需使用含碳量高的純黑碳粉 (K100)，以利紅外線吸收[cite: 1, 2]。
- **機種選擇**：強烈建議使用**單色黑白雷射印表機**，避免彩色碳粉干擾紅外線讀取[cite: 1]。

## 🛠 維修與耗材考量
### 1. 鼓粉設計差異
- **鼓粉一體 (HP 為主)**：碳粉匣與感光鼓結合。列印品質下降時，更換碳粉匣即完成核心維修，對 Maker 最省事[cite: 1, 2]。
- **鼓粉分離 (Brother 為主)**：碳粉與感光鼓分開。碳粉匣單買便宜，但感光鼓老化時需支付較高維修成本[cite: 1]。

### 2. 關鍵耗材壽命
- **加熱組件 (Fuser)**：負責固定碳粉。老化會導致掉粉，使 OID 碼失效。建議加購延長保固[cite: 1, 2]。
- **取紙滾輪**：卡紙主因，屬低預算可自行 DIY 更換的零件[cite: 1]。

## 💡 開發實戰建議
- **列印設定**：務必關閉「省墨模式」，並在驅動程式中手動強制選擇 **1200 DPI**[cite: 1]。
- **品質驗證**：列印後使用 **Sony A73 搭配微距鏡頭** 拍攝點陣碼。確認點陣為清晰、飽滿的實心黑點，且未與背景彩色點混雜[cite: 1, 2]。
- **副廠風險**：副廠碳粉若碳含量不足會導致感應遲鈍。初期建議使用原廠碳粉建立標竿，再逐步替換副廠測試[cite: 1]。
